# NFL Linux Administration Project

## Project Overview

For my Linux midterm project, I decided to create an NFL-themed user and file management system using Ubuntu Server.

The purpose of this project is to gain hands-on experience with Linux commands, user accounts, groups, directory structures, file permissions, and Bash scripting.

I plan to organize Linux users around the NFL's eight divisions, with each team having its own general manager account responsible for managing team files.

## Project Goals

- Install and configure Ubuntu Server using Oracle VirtualBox.
- Practice navigating Linux using terminal commands.
- Create NFL team directories organized by conference and division.
- Create general manager accounts and team groups.
- Configure file ownership and permissions.
- Test whether users can access the appropriate team files.
- Explore Bash scripting to automate administrative tasks.
- Document my progress and challenges using GitHub.

## Project Approach

I will begin with the AFC North division, consisting of the Pittsburgh Steelers, Baltimore Ravens, Cincinnati Bengals, and Cleveland Browns.

Once I have successfully created and tested the accounts, groups, and permissions for those teams, I plan to expand the project to include additional NFL divisions if time allows.

## Documentation

Throughout the project, I will record the time spent working, commands used, challenges encountered, and lessons learned.

The main goal is to develop familiarity with Linux through hands-on practice and troubleshooting.
